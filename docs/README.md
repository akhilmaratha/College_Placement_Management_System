# Project documentation

This directory contains design and implementation references for the College Placement Management System.

- `database/requirements-analysis.md`, `open-questions.md`, `logical-data-model.md`, `er-diagram.md`, and `entity-inventory.md` describe requirements and the relational design.
- `backend/persistence-layer.md` documents JPA mappings and schema ownership.
- `backend/dev2-implementation-plan.md` is an implementation planning note and may not reflect the current code state.

The root [`README.md`](../README.md) is the current setup, API, testing, deployment, and readiness guide. Its module statuses are based on repository inspection; limitations are called out explicitly.
